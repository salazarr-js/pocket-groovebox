# PAM8403 class-D amp (QA03 mini module)

Stereo class-D speaker amplifier — takes the PCM5102's analog line out and drives a small speaker in **BTL (bridge-tied load)**. Sits last in the speaker chain: ESP32-S3 → I2S → PCM5102 DAC → **PAM8403** → speaker. It cannot drive headphones (those come straight off the DAC line out).

| | |
| --- | --- |
| **Role** | Speaker power amp (line in → BTL speaker out) |
| **Chip** | Diodes Inc. PAM8403 |
| **Variant on hand** | "QA03" mini board, fixed gain (no volume pot) |
| **Interface** | Analog stereo in (L/R/GND); 2× BTL speaker out |
| **Operating voltage** | 2.5–5 V (use 5 V for full output) |
| **Output** | 2 × 3 W into 4 Ω; drives 4 Ω or 8 Ω speakers |

## Module pins (QA03 silkscreen)

Three groups: audio **in** + power on the bottom edge, speaker **OUT** on the top edge.

**Bottom — audio input (left) and power (right):**

| Pad | Function |
| --- | --- |
| L | Left audio in (line level, AC-coupled on board) |
| R | Right audio in (line level, AC-coupled on board) |
| GND | Ground |
| 5V (+) | Supply, 2.5–5 V |
| GND (−) | Ground |

> The input `GND` and the power `GND` are the **same net** internally — the
> board just breaks ground out in two spots. One common ground wire to the
> amp is electrically enough; wiring both is fine (redundant, harmless).

**Top — `OUT` to speakers (BTL):**

| Pad | Function |
| --- | --- |
| L− / L+ | Left channel — speaker connects **across** L+ and L− |
| R+ / R− | Right channel — speaker connects **across** R+ and R− |

## Wiring in this project

Input comes from the PCM5102 analog row; power from the ESP32-S3 5 V (VBUS) pin so all grounds are common. Speaker connects in BTL across one channel.

| From | To (PAM8403) |
| --- | --- |
| PCM5102 LROUT | L (in) |
| PCM5102 ROUT | R (in) |
| PCM5102 AGND + ESP32-S3 GND | GND (same net — one common wire) |
| ESP32-S3 5V / VBUS | 5V (+) |
| Speaker terminal 1 | L+ |
| Speaker terminal 2 | L− |

Full connection structure: see [../wiring.md](../wiring.md#connections).

## Notes & gotchas

- **BTL output — never tie L−, R−, or any `OUT` pad to GND.** The outputs are bridge-tied (each speaker terminal is an active half-bridge); grounding one shorts the bridge and can destroy the chip. The speaker floats **between** the + and − of a channel.
- **Not for headphones.** BTL can't drive a headphone jack — headphone/line out comes from the PCM5102. See [pcm5102.md](pcm5102.md).
- **Common ground — wire the DAC AGND to the amp, not just the supply ground.** The amp GND, the DAC AGND, and the ESP32 GND must be the same node. ⚠️ **Gotcha we actually hit:** if you connect the *power* ground but forget the **signal** ground (DAC `AGND` → amp input `GND`), the amp powers up but its input floats with no reference, so it amplifies noise to the rails — a constant, harsh, full-volume tone that **does not respond to the digital `AMPLITUDE` at all** (changing amplitude over a ~42 dB range does nothing). The tell is "every level sounds equally loud." Fix: run a wire from the DAC `AGND` to the amp's input `GND` pad. Verify with a continuity beep: DAC `AGND` ↔ amp input `GND`.
- **Power.** 2 × 3 W can briefly pull more current than a USB port likes. For a test tone it's fine off the devkit 5 V pin; if the ESP32 browns out / resets at high volume, run the amp from its own 5 V supply (powerbank) with grounds tied.
- **Fixed gain.** This QA03 board has no volume pot (≈ 24 dB). Control level upstream via the sketch's `AMPLITUDE` (8000/32767 ≈ −12 dBFS leaves headroom). Lower it if the output distorts.
- **Test tone:** flash [`firmware/03-PCM5102A-test`](../../../firmware/03-PCM5102A-test/03-PCM5102A-test.ino) (440 Hz) — already verified on headphones, so any silence on the speaker is in the amp/speaker leg, not the DAC.
