## Module pins

Labels vary by board; common 8-pin generic layout:

| Pin | Function |
| --- | --- |
| GND | Ground |
| VCC | 3.3 V supply |
| SCL / CLK | SPI clock (SCLK) |
| SDA / DIN | SPI data in (MOSI) |
| RES / RST | Reset (active low) |
| DC | Data / command select |
| CS | Chip select (active low) |
| BLK / BL | Backlight (PWM-able for brightness) |

## Notes & gotchas

- **Write-only SPI** — the host never reads back, so there's no MISO line.
- **170×320 offset = 35.** The ST7789 controller RAM is 240×320; the 170-wide panel sits offset by (240−170)/2 = **35 columns**. Wrong/zero offset → image shifted or wrapped. **TFT_eSPI** applies it automatically when you set `TFT_WIDTH 170` / `TFT_HEIGHT 320` with the ST7789 driver; **LovyanGFX**: set `offset_x = 35`. Also supported by **Arduino_GFX** and the **Adafruit ST7789** library.
- **Colors may need inversion.** ST7789 IPS panels usually want display inversion ON — if colors look negative/washed, toggle it (`tft.invertDisplay(true/false)`).
- Active area 22.695 × 42.72 mm on a 29 × 62 mm PCB — note these for the handheld enclosure layout.
- **Many brands sell this panel** (lcdwiki/MSP1901 matches this board; Waveshare, Adafruit use the same ST7789 panel on a *different* PCB). Code is portable, but **pin order/labels differ between brands** — wire by *this* board's silkscreen, not another brand's.
