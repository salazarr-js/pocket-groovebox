# PCF8575 — 16-bit I2C I/O Expander

16-bit GPIO expander over I2C. Two PCF8575s read the 24-key keyboard (C3–B4) using only 2 ESP32-S3 pins (SDA + SCL), leaving native GPIOs free for encoders, display, and audio. See [wiring.md](../wiring.md#pcf8575--16-bit-i2c-io-expander-keyboard-2-chips) for the full key-to-pin map.

## Module pins

| Pin | Type | Description |
| --- | --- | --- |
| VCC | PWR | Supply voltage. Connect to 3.3 V. |
| GND | PWR | Ground. |
| SDA | I/O | I2C data. Requires external pull-up to VCC (4.7 kΩ). |
| SCL | I | I2C clock. Requires external pull-up to VCC (4.7 kΩ). |
| INT | O | Interrupt output (open-drain, active-low). Pulses low when any input changes. Requires pull-up to VCC. |
| A0, A1, A2 | I | I2C address select. Tie directly to VCC or GND — no pull-ups needed. |
| P00–P07 | I/O | Port 0, 8 quasi-bidirectional I/O pins. |
| P10–P17 | I/O | Port 1, 8 quasi-bidirectional I/O pins. (Note: naming jumps from P07 to P10 — there is no P08 or P09.) |

## I2C address

Address = `0x20 | (A2 << 2) | (A1 << 1) | A0`.

| A2 | A1 | A0 | Address |
| --- | --- | --- | --- |
| GND | GND | GND | 0x20 (default) |
| GND | GND | VCC | 0x21 |
| … | … | … | 0x22–0x27 |

Up to 8 devices on one bus. Default (all address pins to GND) = **0x20**.

## How the quasi-bidirectional I/O works

Each P-pin has a weak current source to VCC and a strong pull-down. At power-on all pins default **HIGH**.

- **Read (input mode):** write `1` to the pin (or leave it at power-on default). An external signal can then pull the pin low against the weak source. Read the pin state back via I2C.
- **Write (output mode):** write `0` to pull the pin low hard (25 mA sink); write `1` to release it to the weak high.

For key reading: wire each key between a P-pin and GND. Pin reads `1` when the key is open; `0` when pressed. No need to write anything first — the power-on default is already the correct input state.

## Reading keys

A single 2-byte I2C read returns all 16 pins at once. Port 0 (P00–P07) arrives in the first byte (LSB = P00), port 1 (P10–P17) in the second byte (LSB = P10).

```cpp
uint16_t readAll(uint8_t addr = 0x20) {
    Wire.requestFrom(addr, (uint8_t)2);
    uint8_t lo = Wire.read();   // P00–P07
    uint8_t hi = Wire.read();   // P10–P17
    return (uint16_t)lo | ((uint16_t)hi << 8);
}
// key N is pressed when bit N of the return value is 0
```

## Interrupt-driven scanning

Connect INT to a free ESP32-S3 GPIO. Attach a falling-edge interrupt. In the ISR (or a flag it sets), do one `Wire.requestFrom()` to read all 16 bits and find which key changed. Avoids polling the I2C bus every loop iteration.

## Notes & gotchas

- **External pull-ups required.** The SparkFun BOB-08130 breakout is bare — it does not include SDA/SCL pull-ups. Add 4.7 kΩ from SDA to 3.3 V and SCL to 3.3 V on the breadboard. Without them the bus will not work.
- **INT is open-drain.** Add a pull-up (4.7–10 kΩ to 3.3 V) on the INT line, or enable the ESP32-S3's internal pull-up on the INT GPIO.
- **Port naming:** the second port is P10–P17, not P08–P15. The `7` in P07 and `10` in P10 are decimal digit pairs (port·pin), not hex. Easy to misread when building bit masks.
- **3.3 V safe.** VCC = 3.3 V is within the 2.5–5.5 V range. The weak high output is also 3.3 V — no level shifting needed between the PCF8575 and the ESP32-S3.
- **I2C bus shared.** The PCF8575 shares SDA/SCL with any other I2C devices added later. Address conflicts are possible — A0/A1/A2 let you resolve them.
